    Flagged issues & UX friction — verification sweep 2026-07-07¶

    Found during a full-functionality verification (8-agent code+test audit swarm + a live browser pass).

    Resolution status (2026-07-07, updated as fixed): - Bug #2 (right-click plants a wrong-space pin in "% vs base") — FIXED + deployed 1c0e61a. - Bug #3 (external trust/remove keyed globally by source label) — FIXED + deployed 1c0e61a (now per bloc::source; browser-verified two independent WEO sliders). - Bug #6 (pure hard-WEO doesn't propagate to a partner view) — DEFERRED as v2 by decision: it's an architectural change to the cross-country cache HIT predicate (the "DE won't move" machinery), not a quick fix. Stays a documented limitation. - Uncertainty shading (separate feature ask, not a bug) — SHIPPED + deployed bfa1e73: charts now scale to the signal and let a wide fan clip instead of squashing the lines (docs/walkthrough unaffected).

    Everything else below is still open for triage — nothing else has been changed.

    How things were checked. Every functional area was traced UI → store → compute → display and its targeted tests were run (~130 tests, all green). Separately, eight headline features were driven in a real browser (Playwright/Chromium, reading the live chart traces): conditioning + propagation, drag-once-conditioned, long-run anchors, uncertainty bands, policy counterfactual, hard-WEO landing, hard-WEO + manual pin + full solve, and US→EA spillover — all passed.

    Bottom line. The tool works. No area is broken. The items below are correctness rough edges (mostly narrow conditions) and first-time-user friction.

    Cross-cutting gap (no single area owned it) — Verified (useStore.ts:408-445)¶

    • Session export/import is not fully lossless. exportSession (lines 411-422) carries scenarios, GVAR pins, anchors(+mode), external(+trust/sources/enabled), and display — but omits the two cross-border spillover toggles (gvarScenarioSpillover, spilloverEnabled), experimentalFeatures, and uncertaintyMode. A save/reload silently drops the user's cross-border-solve and experimental settings. Also: importSession (line 432) does longRunAnchorsByCountry: data.… ?? {}, so importing a valid session file that lacks that key wipes all per-country anchors (no fall-back to current state). (In the session-portability feature I built.)

    UX friction (deduped, actionable)¶

    Discoverability — conditioning (the biggest first-time hurdle): - A chart is read-only until conditioning is on (canDrag requires isConditioned, ChartGrid.tsx:3476). A newcomer sees no way to drag a fresh chart; the "drag to set path" hint only appears after conditioning is on. The empty-conditioning panel only advertises the "condition button" — the right-click-to-plant and drag gestures aren't surfaced. → Let a left-drag on a fresh chart auto-activate conditioning, and/or add a one-line hint ("right-click a chart to plant a target; drag the dot to adjust").

    Controls that silently mutate other controls (same anti-pattern): - "Solve full GVAR" silently latches "Scenario spillovers" ON → every later pin edit then auto-fires a multi-second 50-bloc solve. → Make it a one-shot, or surface "live cross-border solving is now ON." - Compute-in-None silently flips Uncertainty to Quick with no cue (compounds bug #1). → Compute without mutating the visible mode, or flash the Quick button.

    Interactive controls that are no-ops for the current bloc (grey + tooltip on non-GVAR blocs): - The scenario-spillover switch is interactive even on non-GVAR blocs (its own sub-label says "GVAR-linked blocs only"). - The experimental "Iterative GVAR density" toggle is interactable on non-GVAR blocs where flipping it only clears the band and forces a pointless re-Compute.

    Silent no-ops needing feedback: - "Compute optimal rate path" is a silent no-op at default targets (π=2, y=0 → all-zero shocks, no line). → Seed a non-zero default, or hint "set π/y away from baseline." - The four chart-export buttons no-op silently before Plotly is ready. → Disable until chart data is populated, or toast "charts still loading."

    Stale-artifact-without-a-cue: - Editing pins (or toggling experimental) after a Compute silently invalidates the scenario band with no "bands stale — press Compute" hint (the uncertaintyComputed:false flag is already read at ChartGrid.tsx:1490, just not shown).

    Conditioning panel readout / reach mismatches: - The left-panel per-quarter slider is hardcoded ±3 step 0.1 for every variable — larger deviations and level-display vars (oil/FX/equity, stored as 100·log offsets) are unreachable from the panel; only chart-drag reaches them. → Scale per-variable, or add a numeric input. - The panel "levels" readout uses the undrifted baseline and adds a 100·log deviation to a growth-space baseline (nonsensical for level vars; off by the drift when anchors are on). → Reuse conditionedDotDisplayY with the drifted baseline so the panel value matches the dot.

    External-forecast copy / markers: - Teal WEO diamonds are hidden in y/y and %-vs-baseline display modes → an import looks like it failed. → Render converted markers, or note "markers shown in q/q & level view." - Cross-country external propagation needs an explicit "Solve full GVAR" but isn't signalled; a euro-member's external never propagates although the panel copy says "every other variable responds." → Reuse the amber "Solve full GVAR to propagate" prompt for external; note propagation is to the GVAR anchor blocs (US/EA/JP…) only.

    Multi-target solve: - The per-variable/joint toggle only appears at ≥2 targets and defaults to the approximate per-variable mode with no inline explanation (pairs with bug #4). → Add "with 2+ targets, per-variable is approximate — switch to Joint for exact terminals."

    Destructive / lossy actions under-communicated: - Applying a consensus preset silently replaces existing custom anchors for that bloc. → Merge, or warn "(replaces your current targets)." - Per-scenario xlsx "Save" silently drops GVAR pins, anchors, and external forecasts (only full session JSON is lossless — and even that drops the toggles per the gap above). → Extend the Save tooltip; fix the session schema. - CSV/Excel export captures only the active scenario even with up to 4 defined. → Note it, or add per-scenario columns.

    Monitor / coverage labels: - Monitor "Observed releases this update" lists 49/50 blocs because global vars count as a release for nearly every bloc — contradicts the 28-bloc headline-GDP badge. → Exclude global-only entries. - DataCoverage shows the machine token "nowcast" (910 vars) raw. → Add a human label. - The top-bar Docs link points at an external MkDocs site not in this export → 404 on standalone/local deploys. → Gate the link, or document the dependency.

    Verification coverage gaps (worth a targeted test later — not bugs)¶

    • No test exercises any CSV/Excel/PNG/PDF/scenario-xlsx builder (grep-confirmed zero). The export column-alignment, non-finite scrubbing, Variable-Map resolution, and levels↔deviations round-trip on Load are read, not run. → one real export + re-import round-trip test.
    • No perf regression check anywhere — given the multi-second full solve and the "Solve full GVAR latches auto-solve" friction, a slowdown would pass this sweep unnoticed.
    • Untested seams: external × counterfactual (hard WEO composed with a rate/fiscal counterfactual); export of counterfactual/GVAR-propagated state; nowcast-tail drift consistency.
