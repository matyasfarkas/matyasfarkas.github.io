    Fiscal-block expansion — data-availability audit (27 candidate blocs)¶

    Purpose. Extend the 4-variable fiscal block (FREV_GDP, FPEXP_GDP, EFFI, SFA + the debt recursion) to the blocs that lack it. Requested 2026-07-09. Per-economy ingredients audited: quarterly general-government revenue, total expenditure + interest paid (primary expenditure = total − interest), gross debt (d0 seed + SFA residual + back-cast), and the effective interest rate — with the user-sanctioned fallback to the 10-year government bond yield where no interest-paid/maturity data exists. Perimeter (GG vs central government) and seasonal-adjustment seams flagged; the SFA machinery absorbs perimeter seams but they must be declared, never hidden. Sources verified live by the audit agents (Eurostat/BIS APIs fetched; anything unverifiable is marked UNVERIFIED). The no-synthetic-data rule applies throughout: blocked ingredients block the bloc — no interpolation.

    Candidates (50 deployed − 23 with fiscal blocks): CH KR MX AU TR SE PL NO DK IN BR RU ID SA AR ZA TH MY CL CO CR CZ HU IL IS NZ TW.

    Quarterly Government-Finance Data Audit — Group: SE PL DK CZ HU NO IS CH TR RU¶

    Verification method. All Eurostat spans below were pulled live from the Eurostat dissemination API (gov_10q_ggnfa, gov_10q_ggdebt, gov_10q_ggfa, vintage 2026-04-22); BIS spans live from the BIS SDMX API (WS_TC); Statistics Iceland from the PX-Web API; FRED/HMB/Minfin via web verification. Anything I could not confirm end-to-end is marked UNVERIFIED. Repo facts read from app/public/data/bvar/<CC>/spec.json and app/public/data/coverage_manifest.json.

    Cross-cutting findings

    • SE, PL, DK, CZ, HU, NO are all fully covered by the exact same two Eurostat datasets already used for the 22 existing Eurostat fiscal blocs (FREV_GDP/FPEXP_GDP/EFFI/SFA, source string "national/Eurostat gov-finance"): gov_10q_ggnfa (S13; TR=revenue, TE=total expenditure, D41PAY=interest payable; units MIO_NAC and PC_GDP) + gov_10q_ggdebt (S13, GD, MIO_NAC/PC_GDP). All end 2025Q4 (current). These six slot into the existing pipeline with no new provider.
    • EFFI needs no yield fallback for SE/PL/DK/CZ/HU/NO — D41PAY + lagged GD gives the true effective rate, as in the shipped blocs.
    • Seasonal adjustment: gov_10q_ggnfa is NSA; an SCA (seasonally+calendar adjusted) variant exists for SE/PL/DK/CZ/HU/IS but not for NO or CH (verified empty).
    • The repo's Eurostat 10Y source (irt_lt_mcby_m, Maastricht) does NOT cover NO/IS/CH/TR (verified empty) — a yield fallback for those must come from OECD/FRED or national sources.
    • Coverage-manifest windows read "2015Q4→2025Q4" for everything because the manifest reports the 41-quarter estimation panel, not raw source span; YIELD10 lastObs is 2025Q3 with a nowcast flag to 2025Q4.

Eurostat namq_10_gdp covers the six; OECD QNA current-prices covers AU NZ KR IL MX CL CO CR; INDEC (AR), INEGI (MX alt), BCCR cuadro 70 (CR), national sources for ID MY TH TW IN SA TR ZA BR — availability is not in doubt for any of these, but exact series should be pinned during the build.

    Open decisions (user)¶

    1. CH — no quarterly interest-paid series exists; primary expenditure is therefore not constructible without approximating interest ≈ yield × lagged debt (a modelling choice, not a data splice). Options: (a) skip CH fiscal; (b) 3-variable block without EFFI/interest split; (c) yield-approximated interest, clearly documented. Recommend (a) or (c).
    2. IS — no quarterly GG debt verified anywhere (flows are fine, 2002→2026Q1). Options: skip; or CG-perimeter debt from the central bank (unverified, needs a session with databank.is). Recommend skip for now.
    3. SA — clean but only ~37 quarterly obs (2017Q1→) and no yield to extend backwards. Recommend skip (revisit in 2–3 years) unless a short-sample fiscal block is acceptable.
    4. AR — buildable from 2011 (debt-limited) with the group's worst seams (SPN-vs-AC perimeter, USD debt vs ARS flows, default-era breaks). Recommend: defer to a second pass, or accept 2011→ with heavy documentation.
    5. RU — no fiscal block; consistent with the planned bloc drop.
    6. Perimeter policy — accept central/budgetary-government perimeter for the non-European blocs (IN MY ID TH TW KR NZ CR CO MX CL AR SA TR ZA), labelled per-bloc in the manual's data appendix, with the SFA carrying the seam (as it already does for existing blocs)?
